# VALORANT 50体排除タイムアタック　記録システム

スマホから記録を入力し、会場モニターに 1920×1080 でランキングを出すための Web アプリです。

| 画面 | URL | 誰が見る |
|---|---|---|
| 記録入力 | `/input` | スタッフ（パスコード必要） |
| ランキング表示 | `/ranking` | 会場モニター（パスコード不要） |
| 記録の管理 | `/admin` | スタッフ（パスコード必要） |

---

## ランキングの仕様

**部門分けなしの総合 TOP20** です（下絵どおり）。

- 1〜5位：表彰台カード（1〜3位は王冠つき）
- 6〜12位：左のテーブル
- 13〜20位：右のテーブル
- 下部：チャレンジ人数／最新タイム（最後に登録された記録）

### 順位のルール

1. **完走者**（50体撃破）はクリアタイムの短い順に上位
2. **未完走者**（2分で終了）は完走者の下に、倒した体数の多い順
   （タイム欄には `32体` のように表示されます）
3. 同記録は**先に挑戦した人が上位**

「記録なし」は作りません。全員に順位がつきます。

> **部門（小学生／中学生／一般・シニア）は入力だけ残してあります。**
> 画面には出ませんが、CSVには入るので、部門別の表彰を出したいときに使えます。
> 不要なら入力画面から外せます。

# セットアップ（初回のみ・30分ほど）

## 手順1　GitHub にコードを置く

1. GitHub で新しいリポジトリを作る（Private でOK）
2. このフォルダの中身をそのまま push する

```bash
git init
git add .
git commit -m "first"
git branch -M main
git remote add origin https://github.com/<あなたのアカウント>/valorant-ranking.git
git push -u origin main
```

## 手順2　Vercel にデプロイする

1. [vercel.com](https://vercel.com) にログイン
2. **Add New → Project** → 手順1のリポジトリを選ぶ
3. 設定はいじらず **Deploy**

> この時点ではデータベースが無いのでエラーになります。手順3で直ります。

## 手順3　データベース（Neon）をつなぐ

> **注意**：かつての「Vercel Postgres」は2024年12月に提供終了し、**Neon** に移行しました。
> Vercel の画面から数クリックでつながるので、やることはほぼ変わりません。

1. Vercel のプロジェクト画面 → **Storage** タブ
2. **Create Database** → Marketplace の **Neon** を選ぶ
3. プラン：**Free** で足ります（今回の規模なら余裕）
4. 作成すると `DATABASE_URL` がプロジェクトに自動で入ります

## 手順4　環境変数を2つ足す

Vercel のプロジェクト → **Settings → Environment Variables**

| 名前 | 値 | 説明 |
|---|---|---|
| `STAFF_PASSCODE` | 例：`2611` | 当日スタッフに配るパスコード |
| `STAFF_TOKEN` | ランダムな長い文字列 | 内部用。人には見せない |

`STAFF_TOKEN` は適当な英数字を32文字ほど並べれば大丈夫です。
（作るのが面倒なら、ターミナルで `openssl rand -hex 16`）

**登録したら Deployments タブから Redeploy してください。** 環境変数は再デプロイで反映されます。

## 手順5　テーブルを作る（1回だけ）

ブラウザで次のURLを開きます。

```
https://<あなたのアプリ>.vercel.app/api/init?key=<STAFF_TOKENの値>
```

`{"ok":true,"message":"テーブルを作成しました"}` と出れば完了です。

## 手順6　動作確認

1. `https://<あなたのアプリ>.vercel.app/input` を開く
2. パスコードを入れてログイン
3. テストで1件登録する
4. 別のタブで `/ranking` を開き、**3秒以内に反映される**ことを確認
5. `/admin` からテストデータを削除する

# 当日の使い方

## モニター表示

1. モニターにつないだPCで `https://<あなたのアプリ>.vercel.app/ranking` を開く
2. **F11キーで全画面**にする
3. あとは放置。3秒ごとに自動更新され、新しい記録は光ります

> 画面は 1920×1080 で作ってあり、モニターの解像度に合わせて自動で拡大縮小します。
> 4Kモニターでも縦横比が崩れません。

## スマホでの入力

1. スタッフのスマホで `/input` を開き、パスコードでログイン（24時間有効）
2. **ホーム画面に追加**しておくとアプリのように開けます
3. PC番号は一度入れれば端末が覚えます

### 電波が切れても大丈夫です

送信に失敗した記録は**スマホの中に保存され、つながり次第まとめて自動送信**されます。
画面上部に「未送信 ○件」と出るので、イベント終了前に0になっていることだけ確認してください。

## 訂正・削除

`/admin` から、記録の訂正・削除・CSV書き出しができます。
**打ち間違いは必ず出ます。** このページの場所をスタッフ全員に伝えておいてください。

# 見た目を変える

配色は `app/globals.css` の先頭 `:root` にまとまっています。ここだけ変えれば全画面に反映されます。

```css
:root {
  --accent: #e03a2f;  /* 赤（バナーに合わせた色） */
  --gold:   #ffc63d;  /* 1位 */
  --silver: #c9d3dd;  /* 2位 */
  --bronze: #d08a4e;  /* 3位 */
  --bg:     #0b0f14;  /* 背景 */
}
```

ランキング画面のレイアウトは `app/ranking/page.tsx` と、`globals.css` の
`/* ランキング表示 */` 以下です。

表示件数は `app/ranking/page.tsx` の先頭で変えられます。

```ts
const TOP_N = 20;      // 全体で何位まで出すか
const PODIUM_N = 5;    // 表彰台カードの枚数
const LEFT_ROWS = 7;   // 左テーブルの行数（6〜12位）
const RIGHT_ROWS = 8;  // 右テーブルの行数（13〜20位）
```

`TOP_N = PODIUM_N + LEFT_ROWS + RIGHT_ROWS` になるようにしてください。

# 構成

- **Next.js 15**（App Router）
- **Neon Postgres**（Vercel Marketplace 経由）
- 認証はパスコード1つだけの簡易方式（イベント用途のため）
- ランキングは3秒ごとのポーリングで更新

## ファイル

```
app/
  page.tsx             ホーム（各画面へのリンク）
  login/page.tsx       パスコード入力
  input/page.tsx       スマホ用の記録入力
  ranking/page.tsx     1920×1080 のランキング表示（総合TOP20）
  admin/page.tsx       訂正・削除・CSV
  globals.css          配色とレイアウト（★見た目はここ）
  api/
    init/              テーブル作成（初回のみ）
    auth/              ログイン
    records/           一覧取得・登録・訂正・削除
    export/            CSV書き出し
lib/
  db.ts                DB接続と定数（上限120秒・目標50体）
  ranking.ts           順位の計算ロジック
middleware.ts          /input と /admin をパスコードで保護
```
